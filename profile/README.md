## Tools

**[CRIM: Claude's Range of Ions in Materials](https://david-a-muller.github.io/crim/)**
Browser-based Monte Carlo simulators that run in any web browser with nothing to install:

- [CRIM](https://david-a-muller.github.io/crim/crim.html): ion ranges, damage cascades and sputtering, 100 eV to 1 MeV
- [CRIM Sweep](https://david-a-muller.github.io/crim/crim-sweep.html): range, straggle and sputter yield against beam energy, with PDF and CSV export
- [Electron Beam Monte Carlo](https://david-a-muller.github.io/crim/electron.html): trajectories, interaction volume and energy-deposition contours

Source code: [github.com/Ydavid-a-muller/crim](https://github.com/david-a-muller/crim)
